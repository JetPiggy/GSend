# GSend 重新設計說明

2026-10-14 開始。之後的設計判斷以這份為基線；有改動就更新這裏。

## 任務

- GSend 成為 JetPiggy 的產品之一（第二個，GInput 之後）。網站本身就是工具：開網頁就用。
- 賣點：不用線、不用通訊軟件，瀏覽器對瀏覽器直接傳檔案和文字，伺服器不經手、不儲存內容。
- 用家的兩件事：**傳出**（揀檔案或打字 → 攞 4 位數字碼或 QR）和**接收**（打 4 位數字或掃 QR）。之後同一個連線可以來回傳；配對過的裝置不用碼。
- 裝置：桌面和手機都要；接收的一方好多時是手機。
- 新要求：平時有品牌特色（飛豬、墨線）；可以開**工作模式**，開了之後介面只剩文字，看不到飛豬，在公司用不會令人覺得在做私事。

## 品類與標杆

品類：**開網頁即用的跨裝置點對點傳輸工具**。真實畫面存在 `design/benchmarks/`（第三方截圖，只留本機，不入 repo）。

| 看到的 | PairDrop | Wormhole | ToffeeShare | GSend 現在 |
|---|---|---|---|---|
| 首屏放甚麼 | 滿版同心圓雷達，自己的裝置在底部中間，附近裝置浮在圓上 | 星雲滿版底圖，中間一張深色半透明卡：左拖放框、右標題和說明 | 鐵鏽橙滿版，左邊白色拖放卡，右邊標題 + 四個特點 | 左邊大卡（標題、說明、拖放框、文字框、攞碼），右邊窄欄（我的裝置、輸入碼） |
| 為甚麼 | 區網發現：裝置就是要按的東西 | 品牌靠底圖，工具縮成一張卡 | 說服 + 工具同屏 | 傳出和接收同屏 |
| 角色 | 沒有 | 沒有 | 只在標誌（糖果） | 沒有 |
| 控件 | 圖示工具列 | 淺紫膠囊 | 圓角膠囊 | 細框直角掣 |

- 基線（留）：首屏就能拖檔案；數字碼要大、清楚，旁邊有 QR；接收的輸入一眼看到；傳送中看得到對方已進來，可以隨時停。
- 套路（至少一個方向要打破）：「一張拖放卡 + 旁邊一段標題說明」（Wormhole、ToffeeShare、GSend 現在都是）。
- 不要：深色星雲／發光（AI 工具套路）、雷達同心圓（PairDrop 的臉）、膠囊掣。

## 調性

GSend 跟 JetPiggy 的「墨線」方向（見 JetPiggy 品牌網站）：紙底、墨線手繪框、粉紅、紅色手寫批注和印章、飛豬。字型、色板沿用，三個方向只在骨架、主視覺和頁面結構上拉開。

| 刻度 | 取值 | 依據 |
|---|---|---|
| 能量 | 中（比品牌頁低） | 工具每次只用幾十秒；豬在空檔和關鍵時刻出場，不搶操作 |
| 完成度 | 偏粗糲 | 同品牌：馬克筆墨線、紙紋 |
| 密度 | 疏 | 首屏只有傳出和接收兩件事 |
| 分量 | 中偏重 | 粗墨線、大數字碼 |
| 嚴肅度 | 活潑；工作模式切去莊重 | 公司用時不可以像在玩 |

色彩：沿用品牌色板（紙底 `#F7F3E8`、墨黑 `#161616`、豬粉 `#F3A6A4`、紅 `#C4201B`）。GSend 自己的產品色建議取飛豬的**風鏡藍**：深 `#1F5FA8`（名字，紙底上 5.8:1）、淺 `#CFE3F7`（名字的位移陰影），做法同 GInput 的青綠。來源：風鏡是飛行時戴的，GSend 是東西隔空飛過去。GSend 頁內的連結改用墨黑加底線，避免和產品色混淆。

## 第一輪：三個方向（2026-10-14）

對比頁：`design/round-01/style-explorer.html`（現狀 + 三個方向，每個方向附工作模式；桌面 1440x900，只有主狀態，沒有交互）。三個方向共用的示例內容：傳出（拖檔案、打字、產生數字碼）、接收（4 位數字）、已記住的裝置兩部（「我的手機」在線、「書房電腦」離線，是示例資料）、批注「碼 60 秒內有效，用一次就作廢。」、印章「不用線 · 不用通訊軟件 · 無痕」。

共用：字型（jf open 粉圓、Nunito、Titan One、霞鶩文楷批注）、品牌色板、GSend 名用 Nunito 900 風鏡藍 `#1F5FA8` 加 `#CFE3F7` 位移陰影、控件語法（3px 墨線不規則圓角、主掣墨黑白字加粉紅位移影）、不用圖標庫（手畫箭咀）。

工作模式（三個方向同一套做法，等使用者確認）：白底、沒有紙紋；全部改用 Noto Sans HK；1px 灰框、6–8px 圓角；主掣黑底白字、沒有影子；飛豬、表情、紅色批注、印章、導航的豬臉全部收起；GSend 名改為墨黑。版面位置不變，開關前後要按的東西都在同一個地方。

| | 01 隔空 | 02 大號碼 | 03 行李牌 |
|---|---|---|---|
| 北極星 | 兩部機之間只有空氣，飛豬幫你送過去 | 四個大數字就是成件事 | 像寄嘢：綁上行李牌，飛豬送走 |
| 生成引擎 | 具體場景：兩部裝置隔着一段空氣 | 排版本身：數字碼做主角，呼應品牌頁的大字標 | 其他領域的器物：行李牌（牌身 + 撕得開的存根） |
| 首屏骨架 | 三段橫排：傳出紙（540）｜空中（飛豬、虛線航線、批注、印章）｜接收紙（470） | 一句 → 四個 312x312 大格橫跨全寬 → 底部一條傳出 + 已記住的裝置 | 置中一件實物：直身行李牌 620x600，上寄出、下收件存根；左邊印章和批注，右邊細行李牌做裝置 |
| 主視覺 | 飛行姿勢的豬停在航線頂 | 坐着的豬在第四格頂；粉紅大數字 | 飛行的豬用繩吊着行李牌 |
| 記憶點 | 傳送時豬沿航線飛過去，飛到哪裏就是傳到哪裏 | 每打一格豬換表情，打齊四格「啪」蓋印 | 產生數字碼時碼印上牌身；收件時存根被撕走 |
| 工作模式 | 中間收窄成 ⇄ | 數字改幼身黑體 | 牌變直角框，存根用虛線分開 |

差異檢驗：骨架三種都不同（三欄有空隙／全寬一排大格／置中單一物件），主視覺的豬三個姿勢、位置和作用都不同；字型和色板按品牌共用。打破品類套路的是 02（沒有拖放框，整頁可拖）和 03（傳出和接收是同一件實物）。眯眼看明暗：01 兩塊白紙中間一個粉紅點；02 一排四塊加一條；03 中間一塊加兩邊散點。都不像 Wormhole、ToffeeShare 的「一張卡 + 一段標題」。

截圖工具的提示：「卡片裏套卡片」（拖放框、文字框和掣在傳出紙裏面），是表單控件放在面板裏，不是裝飾卡，保留。

## 第二輪：選定 02 大號碼，做成真網站（2026-10-14）

使用者選 02，另外兩點：工作模式「全平」；工作模式的 4 個數字縮細；拖曳有效範圍不變（兩個模式都是整頁）。

### 方向卡

| | |
|---|---|
| 北極星 | 四個大數字就是成件事：打進去就收，派出去就傳 |
| 首屏骨架 | 一句問題（左）＋紅色批注（中）→ 四個大格橫跨全寬，豬坐第四格 → 一行 QR 提示＋三個印章 → 底部一條「或者，傳出」（揀檔案、打字、產生數字碼、已記住的裝置） |
| 主角 | 四個格。收的時候是輸入框（隱形 input 蓋在格上，打齊第 4 位自動加入）；傳的時候同一排格顯示自己的碼，視線不用搬 |
| 字型 | 介面 Nunito＋jf open 粉圓；數字 Titan One（粉紅填色、墨線描邊）；批注和印章霞鶩文楷；使用者內容（檔名、訊息、裝置名）用系統字，因為子集字型沒有任意字 |
| 色彩 | 紙底 `#F7F3E8`、墨 `#161616`、豬粉 `#F3A6A4`、紅 `#C4201B`；GSend 名風鏡藍 `#1F5FA8` |
| 控件 | 3px 墨線不規則圓角；主掣墨底白字加粉紅位移影，按下去「蓋印」移位；連結墨黑加底線 |
| 動效 | ① 主操作回饋：每打一位，數字「蓋印」入格、豬跳一下；② 狀態從哪裏來：產生數字碼後，碼逐格蓋入同一排格；拖檔案入頁面時整頁變成放手區（飛豬＋一句）；傳送中豬騎在進度條最前；③ 首次出場：四格順序落下、豬降落（每次打開只做一次，返回首頁不重播）。減少動態時全部停。 |
| 工作模式 | 白底、無紙紋；系統字；1px 灰框、6–10px 圓角；主掣黑底無影；豬、批注、印章、導航豬臉、進度豬全收；GSend 名轉墨黑；favicon 換成無豬的黑底箭咀；格高由最多 312px 縮到 150px（手機 72–110px）；數字幼身。版面位置不變。 |

### 實作上和原型不同的地方

- **豬換表情改為跳一下**：坐姿沒有不同表情的圖，豬改為每打一位跳一下；位置固定坐第四格（坐其他格會撞到問題句和批注）。
- **深色模式取消**：品牌是紙底，跟品牌網站一樣只有淺色；工作模式就是「素」的那一款。
- **工作模式的記憶**：自己開關的記在本機（`gsend.work`）。從工作模式的人傳來的 QR 或連結帶 `?w=1`，打開的一方這次也是工作模式，但不記住。`index.html` 在第一次繪畫前就加上 class，豬不會閃一下。
- **錯誤留在原位**：碼打錯，紅字出現在格下面（取代 QR 提示），四個數字保留，旁邊有「再試一次」；格不會被推低。
- **手機**：連線中先列收到的檔案，傳送控件在後；手機不能拖檔案，拖放框只剩「揀檔案」掣。
- **私隱頁**：只換外觀（紙底、品牌字、跟隨工作模式），文字未改；不再向 Google Fonts 取字型。
- **字型自己供應**：`scripts/subset-fonts.py` 由 JetPiggy 的字型原檔切出用到的字（粉圓 105 KB、Nunito 27 KB、Titan One 1 KB、文楷 30 KB），放 `public/fonts`，附授權檔。改字串後要重跑。
